5  Interaction

The effect of one explanatory variable depends on the value of another.

This chapter uses GLM notation (\(\eta\)). To focus on the concept of interaction, only normal examples are shown (lm). For Poisson and binomial, try the explore mode of the interactive app at the bottom.

5.1 Summary

  • Slope depends on group
  • Difference depends on group
  • Slope depends on other slope

Mathematical formula:

\[\begin{align} \eta &= \beta_0 + \beta_1 \cdot x_1 + \beta_2 \cdot x_2 + \beta_3 \cdot x_1 \cdot x_2 \\ \tag{1}\label{interactionslope}\\ x_2 &=\begin{cases}1 \quad \text{if B}\\ 0 \quad \text{otherwise} \end{cases} \end{align}\]

Code:

  • R
  • Python
model <- lm(y ~ x * group, data)

Note that x * group is shorthand notation for x + group + x:group.

import statsmodels.formula.api as smf
model = smf.ols("y ~ x * group", data).fit()

Note that x * group is shorthand notation for x + group + x:group.

NoteSymbols & definitions
\(\eta\) — linear predictor

The linear combination of the explanatory variables and their coefficients.
For ordinary linear models, this is just the predicted value of the outcome (\(y\)).

\(x_1\) — explanatory variable (continuous)

The variable the outcome is regressed on.

\(x_2\) — explanatory variable (dummy)

Translates the groups into a number that can be used in the formula. It works like a switch: In group B, it is on (\(x_2 = 1\)) and adds \(\beta_2\) and \(\beta_3 \cdot x_1\) to \(\eta\); in group A (the reference group), it is off (\(x_2 = 0\)).

\(x_1 \cdot x_2\) — interaction term

Allows the effect of one variable to differ depending on the value of the other.
In group B, it adds an additional \(\beta_3\) to the slope. In group A, \(x_2 = 0\), so it adds nothing.

\(\beta_0\) — intercept

Value of the linear predictor (\(\eta\)), when \(x_1\) and \(x_2\) are zero.
Here, \(x_2\) is zero in group A (the reference group), so this is \(\eta\) in group A at \(x_1 = 0\).

\(\beta_1\) — slope

Change in the linear predictor (\(\eta\)), when \(x_1\) increases by one.
In the example, this is the slope of age for diet A (the reference group).

\(\beta_2\) — slope

Change in the linear predictor (\(\eta\)), when \(x_2\) increases by one.
In the example, this is the difference in mean mass between diet B and diet A at age \(0\): The difference in intercept.

\(\beta_3\) — slope (interaction)
Change in the slope of \(x_1\), when \(x_2\) increases by one.
Here, \(x_2\) can only increase from \(0\) (group A) to \(1\) (group B), so this is the difference in the slope of \(x_1\) between group B and group A.
TipExplanation

In the previous chapter, both groups shared a single slope, forcing the lines to be parallel. An interaction removes that restriction: Each group gets its own slope. The coefficient \(\beta_3\) in this case is the difference in slope for group B:

The two lines of A and B are then defined as follows:

Purpose of the coefficients.
Intercept Slope
A \(\beta_0\) \(\beta_1\)
B \(\beta_0 + \beta_2\) \(\beta_1 + \beta_3\)

In a GLM, these are the intercept and slope of the linear predictor (\(\eta\)): The difference in slope (\(\beta_3\)) is on the scale of the link function, not on the scale of the outcome.

Apparently, the interaction is significant (\(p = 8.99 \times 10^{-7}\)). Note that if it were not, the other rows of the regression table still only apply to the reference group (x) and to \(x_1 = 0\) (groupB, groupC): Do not use a model with interaction to draw conclusions about x or group on their own. A non-significant interaction is no reason to refit a model without it. Do so only if the interaction is negligible, that is, if its confidence interval lies entirely within differences that are not biologically relevant (see Model Selection).

P value adjustment: tukey method for comparing a family of 3 estimates

statsmodels has no equivalent of emtrends. The differences between the slopes can be tested with t_test, and corrected for multiple testing with the studentized range distribution, as emtrends does:

import numpy as np
import pandas as pd
from scipy.stats import studentized_range

tt = model.t_test(["x:group[T.B] = 0", "x:group[T.C] = 0", "x:group[T.C] - x:group[T.B] = 0"])
t = tt.tvalue.ravel()
p = studentized_range.sf(np.abs(t) * np.sqrt(2), 3, model.df_resid)
print(pd.DataFrame({"estimate": tt.effect, "SE": tt.sd.ravel(), "t": t, "p (Tukey)": p},
                   index=["B - A", "C - A", "C - B"]))
       estimate        SE         t     p (Tukey)
B - A  1.147696  0.191498  5.993266  5.204982e-07
C - A  0.481309  0.191006  2.519859  3.852672e-02
C - B -0.666387  0.186914 -3.565204  2.190286e-03

After multiple testing correction, all three slopes differ significantly from each other.

Mathematical formula:

\[\begin{align} \eta &= \beta_0 + \beta_1 \cdot x_1 + \beta_2 \cdot x_2 + \beta_3 \cdot x_1 \cdot x_2 \\ \tag{2}\label{interactiondummy}\\ x_1 &=\begin{cases}1 \quad \text{if B}\\ 0 \quad \text{otherwise} \end{cases}, \\ x_2 &= \begin{cases}1 \quad \text{if treated}\\ 0 \quad \text{otherwise} \end{cases} \end{align}\]

Code:

  • R
  • Python
model <- lm(y ~ group * treatment, data)
import statsmodels.formula.api as smf
model = smf.ols("y ~ group * treatment", data).fit()
NoteSymbols & definitions
\(\eta\) — linear predictor

The linear combination of the explanatory variables and their coefficients.
For ordinary linear models, this is just the predicted value of the outcome (\(y\)).

\(x_1, x_2\) — explanatory variables (dummy variables)

Translate both categorical variables into numbers that can be used in the formula. Each works like a switch: \(x_1\) is on in group B and adds \(\beta_1\) to \(\eta\); \(x_2\) is on for treated observations and adds \(\beta_2\); for untreated observations in group A, both are off.

\(x_1 \cdot x_2\) — interaction term

Allows the effect of one variable to differ depending on the value of the other. It works like a switch too: It is only on for treated observations in group B, and then adds \(\beta_3\) to \(\eta\).

\(\beta_0\) — intercept

Value of the linear predictor (\(\eta\)), when \(x_1\) and \(x_2\) are zero.
Here, both are zero for untreated observations in group A (the reference groups), so this is \(\eta\) in untreated group A.

\(\beta_1\) — slope

Change in the linear predictor (\(\eta\)), when \(x_1\) increases by one.
In the example, this is the difference in mean dry mass between variety B and variety A, for untreated plants.

\(\beta_2\) — slope

Change in the linear predictor (\(\eta\)), when \(x_2\) increases by one.
In the example, this is the difference in mean dry mass between treated and untreated plants, for variety A.

\(\beta_3\) — slope (interaction)
Change in the slope of \(x_1\), when \(x_2\) increases by one.
Here, this is how much the difference between group B and group A differs between treated and untreated. Or equivalently, how much the difference between treated and untreated differs between group B and group A.
TipExplanation

In the previous chapter, the difference between treated and untreated was the same in both groups. An interaction removes that restriction: Each group gets its own difference. The coefficient \(\beta_3\) in this case is the difference in differences for group B:

The means of the four combinations are then defined as follows:

Purpose of the coefficients.
Untreated Treated
A \(\beta_0\) \(\beta_0 + \beta_2\)
B \(\beta_0 + \beta_1\) \(\beta_0 + \beta_1 + \beta_2 + \beta_3\)

In a GLM, these are values of the linear predictor (\(\eta\)): The difference in differences (\(\beta_3\)) is on the scale of the link function, not on the scale of the outcome.

Mathematical formula:

\[\begin{align} \eta &= \beta_0 + \beta_1 \cdot x_1 + \beta_2 \cdot x_2 + \beta_3 \cdot x_1 \cdot x_2 \tag{3}\label{interactionslopeslope} \end{align}\]

Code:

  • R
  • Python
model <- lm(y ~ x1 * x2, data)
import statsmodels.formula.api as smf
model = smf.ols("y ~ x1 * x2", data).fit()
NoteSymbols & definitions
\(\eta\) — linear predictor

The linear combination of the explanatory variables and their coefficients.
For ordinary linear models, this is just the predicted value of the outcome (\(y\)).

\(x_1, x_2\) — explanatory variables (continuous)

The variables the outcome is regressed on.

\(x_1 \cdot x_2\) — interaction term

Allows the effect of one variable to differ depending on the value of the other.
At \(x_2 = 0\), it adds nothing to the slope of \(x_1\); at \(x_2 = 1\), it adds \(\beta_3\); at \(x_2 = 2\), it adds \(2 \cdot \beta_3\); and so on.

\(\beta_0\) — intercept

Value of the linear predictor (\(\eta\)), when \(x_1\) and \(x_2\) are zero.

\(\beta_1\) — slope

Change in the linear predictor (\(\eta\)), when \(x_1\) increases by one.
In the example, this is the slope of nitrogen for plants that received no phosphorus.

\(\beta_2\) — slope

Change in the linear predictor (\(\eta\)), when \(x_2\) increases by one.
In the example, this is the slope of phosphorus for plants that received no nitrogen.

\(\beta_3\) — slope (interaction)
Change in the slope of \(x_1\), when \(x_2\) increases by one.
Or equivalently, the change in the slope of \(x_2\), when \(x_1\) increases by one.
TipExplanation

In the previous chapter, the slope of \(x_1\) was the same at any value of \(x_2\), which made the model a flat plane. An interaction removes that restriction: The plane is curved. The coefficient \(\beta_3\) in this case is the change in the slope of \(x_1\), when \(x_2\) increases by one:

Grouping the terms shows that \(x_2\) changes both the intercept and the slope of \(x_1\):

\[\eta = \underbrace{(\beta_0 + \beta_2 \cdot x_2)}_{\text{intercept}} + \underbrace{(\beta_1 + \beta_3 \cdot x_2)}_{\text{slope}} \cdot x_1\]

Example interpretation of the coefficients.
Intercept Slope
\(x_2 = 0\) \(\beta_0\) \(\beta_1\)
\(x_2 = 1\) \(\beta_0 + \beta_2\) \(\beta_1 + \beta_3\)
\(x_2 = 2\) \(\beta_0 + 2 \cdot \beta_2\) \(\beta_1 + 2 \cdot \beta_3\)

In a GLM, these are the intercept and slope of the linear predictor (\(\eta\)): The change in slope (\(\beta_3\)) is on the scale of the link function, not on the scale of the outcome. See the interactive app at the bottom of the page for examples.

B. There is no significant difference between the diets at age \(0\)
C. There is no significant difference between the diets at any age

TipLearn why

A. Not significant does not mean no difference. Moreover, the row only applies at one age (see B).
B. In a model with interaction, groupB is the difference in intercept: the difference between the diets where \(x_1 = 0\). That is all this row tells us. Since the youngest fish in these data is half a year old, it is not a very interesting age either.
C. The slopes differ significantly (x:groupB), so the difference between the diets grows with age. At age \(3\), for example, the estimated difference is \(\hat{\beta}_2 + 3 \cdot \hat{\beta}_3 = 3.74\) g.
D. Without groupB, both lines would be forced to start at the same intercept, and the other rows would change meaning. A variable that is part of an interaction stays in the model.
